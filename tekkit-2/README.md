# Tekkit 2 Mods

This directory is reserved for mods adapted specifically to Tekkit 2. No compatible mod source or release jars have been ported here yet. Do not copy the Tekkit Classic 1.2.5 jars into this directory; they are incompatible with Tekkit 2.

Add each port as a self-contained project here, including its own source, build instructions, compatibility notes, and validation evidence. Tekkit 2 releases will use independent versions and tags such as `tekkit-2-v1.0.0`.
